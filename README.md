# Bluesom Conservation

A modern, responsive static website for **Bluesom Conservation — Protecting Somalia's Blue Future.**

## GitHub Pages

1. Create a new GitHub repository, for example `bluesom-conservation`.
2. Upload all files and folders from this project.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide the website URL.

## Important

This is a static GitHub Pages website. The contact form and photo submission form are client-side demos. To actually receive messages or store uploaded photos, connect a trusted form/upload service and update the website accordingly.

The donation interface is also a placeholder until an official payment provider is connected.

## Customize

- Edit text in the HTML files.
- Edit colors and layout in `css/style.css`.
- Edit English/Somali translations in `js/language.js`.
- Add real photos to the `images/` folder and update image references.
- Replace all `[ADD ...]` placeholders with verified Bluesom Conservation information.
- Replace demo news and statistics with verified information.

Do not publish invented statistics, partnerships, addresses, contact details or achievements as real organizational claims.
