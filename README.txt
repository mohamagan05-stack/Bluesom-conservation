# BlueSom Conservation Website

This is the first version of the BlueSom Conservation website.

## Files
- `index.html` — website structure and content
- `style.css` — design and responsive layout
- `script.js` — mobile menu, year, and contact-form message

## Important before publishing
Replace the placeholder email `info@bluesomconservation.org` with your real official email.
You can also replace the project descriptions with your actual projects.

## Free publishing
A simple free option is GitHub Pages. Create a GitHub repository, upload these three website files, and enable GitHub Pages from the repository settings.
